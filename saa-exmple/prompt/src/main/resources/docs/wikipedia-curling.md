# 2022年冬季奥林匹克运动会冰壶赛事
## 赛事基础概况
2022年冬奥会冰壶比赛在**国家游泳中心（冰立方）**举办，场馆属于奥林匹克公园场馆群。冰壶赛事贯穿整届冬奥周期，比赛日期：2月2日—2月20日。这是冰壶第八次成为奥运会正式竞赛项目。

男子、女子、混合双人三个分项各10支队伍参赛。混合双人项目第二次登上冬奥舞台，参赛规模扩容。
冰壶总参赛名额120个（男女各60席），相较2018冬奥会增加4席；共设立3个竞赛项目：男子四人冰壶、女子四人冰壶、混合双人冰壶。

## 参赛资格规则
除东道主自动获得全部参赛名额外，男、女子四人冰壶资格分两种获取渠道：
1. **直通名额**：2021世界冰壶锦标赛排名前六队伍直接晋级（6支）；
2. **资格赛名额**：通过2021奥运资格赛决出剩余3支晋级队伍。

### 奥运资格赛参赛构成
资格赛设置主办国，参赛队伍包含：
- 2021世锦赛未拿到奥运资格的队伍
- 奥运预选资格赛决出的2支优胜队
  奥运预选资格赛面向世界冰壶联合会全部会员协会开放。

### 混合双人资格规则
2022混合双人参赛队伍由8支扩至10支：
1. 2021世界混合双人冰壶锦标赛前7名直通；
2. 剩余2个名额由混合双人专项奥运资格赛决出。
   资格赛参赛方：指定主办国 + 积分最高且未晋级的15个国家。
   东道主中国自动获得三个项目全部席位，每个分项凑齐10队。
