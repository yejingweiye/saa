# Model Context Protocol (MCP) Java SDK
**模型上下文协议（MCP）Java SDK**

> MCP协议规范的Java语言实现，提供同步与异步客户端，用于和MCP服务端交互。

## 概述
本SDK实现了模型上下文协议，通过标准化接口实现AI模型与外部工具的无缝集成。
同时支持同步、异步两种通信模式，能够适配多种多样的业务场景与系统集成需求。

## 功能特性
- 同步客户端与异步客户端实现
- 支持全部MCP标准操作：
  - 工具发现与工具执行调用
  - 资源管理与资源模板
  - 提示词处理和管理
  - 资源订阅机制
  - 服务初始化与心跳检测（ping）
- 支持基于标准输入输出（Stdio）的服务传输
- 基于Project Reactor实现响应式编程支持
